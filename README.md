# hello-claude

A tiny sample project for practicing the GitHub pull request workflow.

## What this is

`greet.py` has one function, `greet(name)`, that returns a friendly greeting
string. Run it directly to print a greeting to the console.

## Usage

```bash
python greet.py Ada
```

## Development

Install dependencies and run the tests:

```bash
pip install -r requirements.txt
pytest
```
